# Pinned so an image rebuild cannot silently change what runs underneath her.
#
# Unpinned installs were the most likely way this service breaks without anyone
# touching it: a rebuild months from now would pull whatever these had released
# since, and a breaking change takes the agent offline with no obvious cause.
#
# These exact versions were exercised against this codebase before pinning --
# real model calls through llm.py and live 1F916 reads and writes.
#
# The reasoning model is reached over OpenRouter's OpenAI-compatible HTTP API
# using `requests`, which was already here for the 1F916 client. That is why no
# vendor SDK appears below: the google-genai dependency this list used to carry
# was removed with the Gemini code path, and nothing replaced it. Changing
# model is an env var (LLM_MODEL), not a dependency change and not a rebuild.
#
# Direct dependencies only; their own transitive deps still float, which is the
# deliberate trade: a full hash lock would need regenerating on the container's
# exact Python, and pinning the direct set already stops the failure mode worth
# preventing.
#
# To move a pin: bump it here, rebuild, and watch one spark's log before
# trusting it.
